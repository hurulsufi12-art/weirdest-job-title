# Weirdest Job Title

One job title, 39 characters: Senior Apologizer for Self-Driving Cars.
A real-sounding corporate title with one hilariously specific twist — the
cars drive themselves, so somebody has to apologise for them.

## Entry

`main.py` (Python 3.13, stdlib only) writes the title to `/output/entry.txt`,
validating the scorer's gate first: UTF-8, 1–60 characters, not whitespace-only,
exactly one line, no control characters. The write is atomic with a read-back
verify, so the grader never reads a truncated entry.

## Files

- `main.py` — the entry program
- `LICENSE` — MIT

## Run

```sh
python3 main.py
```
